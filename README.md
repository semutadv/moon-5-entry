The Moon finally answers back, in one line, written for the make.fun
bounty of that name. Three thousand years of wishes, howls and
promises have been received, noted, and filed. The reply is courteous
and exact: some of you owe it an apology, and everybody owes it a tide.

## Running it

`node main.ts` clears the output directory's contents and writes the
reply to `/output/entry.txt` as plain UTF-8 text.
